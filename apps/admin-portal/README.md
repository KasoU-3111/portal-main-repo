# IBD-Admin

Build a polished, modern healthcare administration dashboard for a platform called:

MERIDIAN IBD

Subtitle:

Clinical Administration Portal

IMPORTANT:

This is a PRIVATE ADMINISTRATION PLATFORM.

Do NOT create a public landing page.
Do NOT create a marketing website.
Do NOT create a doctor dashboard.
Do NOT create a patient dashboard.
Do NOT create the doctor collaboration platform.

This is a completely standalone Admin Panel prototype.

The first version should contain:

+
